# Kenshi · Wanted

A checklist of the **Kenshi** wanted bounties. Mark each criminal as captured and look up their location, reward and lore.

## Run locally

This is a static site (plain HTML, CSS and JavaScript, no build step or dependencies). Because it uses ES modules and loads JSON files, it has to be served over HTTP.

```bash
python -m http.server 8000
```

Then open http://localhost:8000.
